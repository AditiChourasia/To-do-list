# Todo List App

This is a simple and elegant todo list application built to help you stay organized and keep track of your tasks.

## Features

- **Add new todos:** Quickly add new tasks to your list.
- **Delete todos:** Remove tasks you've completed.
- **Search todos:** Easily find specific tasks using the search bar.
- **Responsive design:** The app is designed to work on various screen sizes.

## Technologies Used

- **HTML5:** For the basic structure of the application.
- **CSS3:** For styling and layout.
- **JavaScript (ES6):** For the application's functionality.
- **Bootstrap:** For responsive design and pre-styled components.
- **Font Awesome:** For icons.

## How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/todo-list-app.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd todo-list-app
   ```
3. **Open `todoapp.html` in your web browser.**

That's it! You can now start adding, managing, and searching for your todos.
